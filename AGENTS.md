# Apollo-mod — Agent Reference

## Project

Community fork of [JusperLee/Apollo](https://github.com/JusperLee/Apollo) — a GAN-based audio restoration model targeting codec-compressed audio (MP3, AAC, Opus). Reworked for single-GPU fine-tuning on user-supplied paired LQ/HQ WAV datasets.

## Architecture

- `look2hear/models/apollo.py` — Generator. Band-split network (BSNet) + Roformer layers. STFT/iSTFT in float32 regardless of training precision. Hann window registered as a persistent buffer.
- `look2hear/discriminators/frequencydis.py` — Frequency discriminator for GAN training.
- `look2hear/system/audio_litmodule.py` — Lightning module. Handles train/val steps, gradient checkpointing, val audio saving.
- `look2hear/losses/` — GAN losses + matrix loss.
- `paired_datamodule.py` — Datamodule. Loads chunked LQ/HQ WAV pairs from `chunks/`. Augmentation pipeline (live + cached) controlled via yaml.

- `train.py` — Entry point. Calls `prepare_data()` to auto-chunk `data/` into `chunks/` on first run, then trains.
- `inference.py` — Entry point. Loads weights (HF shortname, `.ckpt`, `.pth`/`.bin`), processes audio in overlapping 30s chunks with crossfade stitching.
- `configs/apollo.yaml` — Base model config (`feature_dim=256`).
- `configs/apollo_uni.yaml` — Universal model config (`feature_dim=384`).

## Data Layout

```
data/
  train/  lq/  hq/     ← raw WAV pairs, filenames must match
  val/    lq/  hq/

chunks/                 ← auto-generated by train.py on first run
  train/  LQ/  HQ/
  val/    LQ/  HQ/
```

Delete `chunks/` to force re-chunking (required after changing `segment_sec` or augmentation).

## Key Config Knobs

All in `configs/apollo.yaml` (or `apollo_uni.yaml`):

- `training.n_layers_to_freeze` — freeze front BSNet layers to reduce VRAM / catastrophic forgetting
- `training.grad_accum_steps` — simulate larger batch without extra VRAM
- `system.gradient_checkpointing` — recompute activations on backward (~30% more compute, large VRAM saving)
- `datas.segment_sec` — chunk length; changing requires deleting `chunks/`
- `optimizer.type` — `adamw`, `adamw_8bit`, or `cpu_offload`
- `augmentation` — `live` (per-epoch) and `cached` (baked at chunk time) augmentation blocks

## Commands

```bash
# Install / activate environment
./apollo.sh           # Linux/macOS
apollo.bat            # Windows

# Train
python train.py --conf_dir=configs/apollo.yaml

# Inference
python inference.py --in_wav input.mp3 --out_wav output.wav --weights lew_v2

# Monitor training
tensorboard --logdir ./experiments
```

## Known Constraints

- Input must be WAV. MP3/FLAC rejected by the datamodule.
- Apollo expects `sr=44100`. Do not change.
- cuFFT does not support fp16 for non-power-of-two FFT sizes — STFT always casts to float32.
- `sync_dist` and `all_gather` removed from Lightning module — single GPU only.
